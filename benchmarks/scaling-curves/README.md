# Scaling curves

Real browser input is applied to 8, 32, 96, 256, and 512 distinct controlled components in the same production-built six-framework application. Every point verifies every visible output before recording its operation. The machine-readable result publishes individual scale-point timings and distribution statistics.

```bash
node benchmarks/bench.mjs --quick scaling-curves
node benchmarks/bench.mjs scaling-curves
```
