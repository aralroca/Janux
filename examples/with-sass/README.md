# Sass, zero config

An accent palette whose four variant classes are generated by a single `@each` loop over a Sass map:

- **The extension is the configuration** — name the entry `src/styles.scss` (`.sass` and `.less` work too) and `janux dev` / `janux build` compile it. No `vite.config`, no PostCSS wiring; the only thing to install is `sass` itself.
- **Always one sheet** — whatever the entry's extension, the build emits `dist/client/styles.css`, the single stylesheet the HTML shell links.
- **Everything resolves at build time** — variables, nesting, `@mixin` and `@each` leave no trace in the output: the browser receives plain CSS and 0 KB of Sass.
- **Partials work as expected** — `src/styles/_tokens.scss` holds the tokens and is pulled in with `@use`.
- **Generated classes, driven by state** — the `palette` island swaps between `.accent-ocean`, `.accent-moss`, `.accent-ember` and `.accent-plum`, none of which were written by hand.

```bash
bun install
bun run dev     # http://localhost:4321
```

```bash
bun run build   # then: bun run start
```

## The loop that earns the preprocessor

```scss
$accents: ('ocean': #0062ff, 'moss': #12805c, 'ember': #d1442f, 'plum': #7b3fbf);

@each $name, $color in $accents {
  .accent-#{$name} {
    border-color: $color;
    h2 { color: $color; }
  }
}
```

See [Styles → Sass](https://janux.build/docs/styles/sass) for the full picture.
